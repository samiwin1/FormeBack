# Static Resources

## Logo File

Place your company logo here as `forme-logo.png` for certificate generation.

**Requirements**:
- Filename: `forme-logo.png`
- Format: PNG
- Recommended size: 200x200 pixels or similar square/rectangular format
- Transparent background recommended

The logo will be automatically included in generated PDF certificates.

If the logo file is not found, certificates will be generated without a logo.
