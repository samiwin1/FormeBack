# How to Add the ForMe Logo

## Instructions:

1. Save your ForMe logo image as: `forme-logo.png`
2. Place it in this directory: `formecertification/certification-service/src/main/resources/static/`
3. The logo should be in PNG format for best quality
4. Recommended size: 300x300 pixels or larger (it will be automatically scaled)

## File Location:
```
formecertification/
  certification-service/
    src/
      main/
        resources/
          static/
            forme-logo.png  <-- Place your logo here
```

## The PDF generation service is already configured to use this logo!

Once you add the logo file, it will automatically appear at the top of all generated certificates.
